# Affordance labels for RGBD datasets
This repository contains affordance labels for the NYU, Sun 3D, Sun RGBD, Scene NN, Building Parser, and (partially) the Matterport dataset. 


The procedure for collecting this data is described in _Macro and Meso Affordance Data Collection to Enrich
SunRGBD Dataset_, Luc Schoot Uiterkamp & Gwenn Englebienne, _in print_
